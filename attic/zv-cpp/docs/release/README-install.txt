zv release archive

This archive contains the zv and zv-client binaries plus supporting release metadata.

Quick install:
  curl -fsSL https://raw.githubusercontent.com/nburrus/zv/main/scripts/install.sh | bash

Manual install:
  1. Extract this archive
  2. Copy zv and zv-client to ~/.local/bin/
  3. chmod 755 ~/.local/bin/zv ~/.local/bin/zv-client
